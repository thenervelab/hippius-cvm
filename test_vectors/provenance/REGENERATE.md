# `test_vectors/provenance/` — image-provenance known-answer vector

Pinned inputs + frozen output for `hippius-image-provenance`'s
known-answer test (`cargo test -p hippius-image-provenance --test
kat`). The test freezes the signed `provenance.cbor` produced for
this exact input tuple under the committed dev §22 root key, so a
canonical-CBOR change, a key edit, or a fixture edit that shifts the
signature fails CI loudly instead of silently moving every
production provenance signature.

## Files

| File | Provenance |
|---|---|
| `measurement.json` | A pinned, synthetic `hippius-uki-measure` SNP envelope (`measurement_kind = snp_launch_digest_v1`). The `measurement_hex` reuses the `test_vectors/snp/` known-answer launch digest; the component hashes are fixed synthetic values (`hippius-image-provenance` records them verbatim — it never recomputes them). |
| `artifact.bin` | Synthetic — fixed ASCII bytes standing in for a signed UKI. Its SHA-256 becomes `artifact_sha256` + the content-addressed S3 key; its length (92 bytes) is pinned in `measurement.json`'s `uki_size_bytes`. |
| `provenance.cbor` | **Frozen output** — the canonical-CBOR `SignedProvenance` envelope `sign` produces for the tuple above, signed by `packer/kbs-uki/keys/dev/provenance-root.dev.ed25519`. |

The build timestamp is pinned in the test itself
(`KAT_BUILT_AT_UNIX` in `binaries/image-provenance/tests/kat.rs`) —
Ed25519 signing is deterministic, so a fixed key + fixed body yields
a fixed signature.

## Regenerating the frozen output

`provenance.cbor` and the committed dev public key
(`packer/kbs-uki/keys/dev/provenance-root.dev.ed25519.pub`) are
both regenerated by one `#[ignore]`d helper. Run it **only** for a
deliberate change — a canonical-encoding change in
`hippius_types::provenance`, an intentional fixture edit, or a
rotation of the dev root seed:

```bash
cargo test -p hippius-image-provenance --test kat \
    regenerate_committed_vectors -- --ignored --exact
```

Then review the diff to `provenance.cbor` / the `.pub` file, and —
because the launch measurement → provenance binding changed — note
that a real turn-up would re-run the §22 allowlist ceremony.

The dev root seed itself MUST NOT be rotated casually; see
`packer/kbs-uki/keys/dev/README.md`.
