# `test_vectors/heartbeat/` — miner heartbeat known-answer vectors

Pinned input tuple + frozen outputs for the §K miner-agent periodic
signed heartbeat (ARCHITECTURE.md §K / §13, PR-MA-6). The known-answer
test (`cargo test -p hippius-types --test heartbeat_kat`) freezes the
exact canonical-CBOR bytes `hippius_types::heartbeat` produces, so a
canonical-encoding change, a key edit, or a fixture edit that shifts
the signature fails CI loudly instead of silently moving every
production heartbeat signature.

The signed vector is a **real** signed envelope — the inner body is
signed by a fixed test Ed25519 key. Ed25519 signing is deterministic,
so a fixed key + fixed body yields a byte-exact signed envelope.

## Files

| File | Provenance |
|---|---|
| `heartbeat_body.cbor` | **Frozen output** — `MinerHeartbeat::canonical()` for the pinned tuple (the signature preimage). |
| `signed_heartbeat.cbor` | **Frozen output** — `SignedMinerHeartbeat::canonical()`: the `{body, sig}` envelope, `sig` = Ed25519 over `body` by the pinned test key. |

## Pinned input tuple

The tuple is pinned in the test itself (`kat_heartbeat()` +
`KAT_SEED` in `hippius-types/tests/heartbeat_kat.rs`): a fixed
`miner_id`, `timestamp_unix`, `sequence`, the VM / CPU / memory
counters, and a synthetic 32-byte Ed25519 signing-key seed.

## Implementing a parallel encoder

1. Construct the same `MinerHeartbeat` with the same fixed fields.
2. Encode it with your deterministic-CBOR encoder → must equal
   `heartbeat_body.cbor` byte-for-byte.
3. Ed25519-sign that body with the pinned seed; wrap `{body, sig}` and
   canonical-encode → must equal `signed_heartbeat.cbor`.

If it doesn't, your impl's encoder is drifting — fix it, do not update
the committed vector.

## Regenerating the frozen outputs

Regenerated by one `#[ignore]`d helper. Run it **only** for a
deliberate change — a canonical-encoding change in
`hippius_types::heartbeat`, an intentional fixture edit, or a rotation
of the test seed:

```bash
cargo test -p hippius-types --test heartbeat_kat \
    regenerate_committed_vectors -- --ignored --exact
```

Then review the diff to both `.cbor` files.
